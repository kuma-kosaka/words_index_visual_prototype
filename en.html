Sphere sizing

Diameter scales with fragment count. Largest sphere (食・料理, 52 fragments) = 102px core. Smallest formed (天気, 5) = 52px.

Surface keywords

2-3 keywords visible on sphere surface. Opacity decreases for secondary terms. User can identify network theme without tapping.

New network badge

Amber dot with "!" indicates a newly formed network. Number badge shows new connections since last visit.

Forming state

Dashed border + reduced opacity. Progress indicator shows links toward threshold (e.g. 2/3). Not yet tappable.

Color encoding

Each network has a unique color ramp. Color persists across all views, providing spatial memory cues.

Depth encoding

Three layers: near (100% opacity), mid (55%, 88% scale), far (25%, 75% scale). Simulates 3D sphere on 2D screen.

Dynamic connection lines

Only 3-4 nearest nodes show lines. On drag-rotate, lines fade in/out with 300ms easing synced to finger velocity.

Detail popup

Bottom sheet with kanji + reading + POS tag, source memory, AI-generated examples with target word highlighted, and wormhole links.

Wormhole indicator

Purple glow dot on nodes that exist in other networks. Tap the link in popup to trigger cross-network traversal.

Exit gesture

Pinch-out = camera pulls back, sphere contracts, surrounding spheres fade in. Continuous zoom, no page transition.

Clipboard auto-detect

On open, checks clipboard for Japanese. Shows toast with preview. One tap to auto-fill. Reduces capture to 2 taps.

AI auto-analysis

Instant: POS detection, furigana reading, probable meaning. No user action. Correction via tap.

Source tags

Single-tap presets with emoji. One active at a time. Maps to personal memory dimension in network clustering.

Critical path

FAB → type word → save. 3 taps. Everything else (note, tags) is optional enhancement.

Dormant recall

In-app banner

Semantic clustering

Core fan terms (推し, メンバー, 番組) cluster tight in foreground. Performance vocab (セトリ, MC) sits mid. Lottery terms (当選, 落選) drift to back.

Cross-network wormholes

ライブ → 移動・交通 (travel)
握手会 → 敬語 (polite speech)
Color-coded by destination. One node can bridge multiple networks.

Three-layer examples

Layer 1: Japanese with target highlighted. Layer 2: English translation. Layer 3: Full furigana — kanji readings in teal, target word in coral. Only kanji annotated; hiragana skipped.

Personal memory in AI examples

"九月のライブ" maps to Miyazaki Hinata Fes. The tool mirrors your life back in Japanese, not generic textbook sentences.
